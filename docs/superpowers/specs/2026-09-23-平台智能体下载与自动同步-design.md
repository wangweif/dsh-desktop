# 平台智能体下载到本地与自动同步（preset 化）设计

- 日期：2026-09-23（2026-09-24 真实平台验收通过）
- 状态：已实施
- 涉及仓库：`dsh-desktop`（Electron 宿主）、`agent_platform`（FastAPI，http://localhost:3002）
- 前置：[启动登录与用户信息展示](2026-09-23-启动登录与用户信息展示-design.md)（session cookie 归 EnterpriseAuth 持有）

## 背景与目标

把 agent_platform 上的智能体**下载到客户端本地**，下载后与 dsh 自带智能体（harness preset）一样在新建会话选择器中使用；平台给用户/用户组分配智能体后，客户端登录即自动拉取。

已确认的决策：

| 决策点 | 结论 |
| --- | --- |
| 能力边界 | 下载版 = 平台组装的 persona 系统提示词 + harness 本地工具子集 + harness 当前模型；平台知识库/平台 DB 工具/多轮记忆不随下载（二期再议） |
| 运行形态 | 平台智能体映射为本地 preset（`.agent-presets/nkyz-<平台uuid>/`），复用 harness 原生选择器与会话，不另建前端 |
| 入口 | 独立页面 `build/agents.html`（列表/下载/更新/两步卸载）+ harness 侧边栏注入"平台智能体"按钮 |
| 自动同步 | 登录点"进入"与启动会话恢复成功后后台对齐平台分配：新分配安装、新版本更新、一致的跳过 |
| 卸载语义 | 用户主动卸载记入排除名单（`.excluded-agents.json`），自动同步不装回；平台取消分配的本地保留不自动删 |
| 平台侧 | 导出接口按合同实现（`docs/平台智能体导出接口合同.md`），桌面端零特殊分支 |

## 关键机制（实施时验证）

- harness preset 发现无缓存（`@deepseek-ai/dsh-agent-presets` lib/index.js "Discovery is unmemoized"）：写盘后**即时**出现在选择器，无需重启。
- preset 目录名须匹配 `/^[a-z0-9][a-z0-9-]*$/`；扫描只读 `agent.cordis.yml` + `preset.yml`，目录内额外文件（来源 manifest）被容忍，dot 文件/目录被忽略——排除名单、临时/备份目录由此落位。
- persona `complete:true` 使平台提示词成为唯一系统提示词；不设 `includeRuntimeContext`（保留工作目录等运行时上下文——工具面含 bash/fs）。
- **陷阱**：dsh-system-prompt 的 interpolate 对未注册 `{{name}}` 变量直接 throw → 平台提示词写盘前做 `{{` → `{ {` 配对破坏（循环替换收敛 `{{{x}}}` 跨界拼接）。
- preset 不管模型路由 → 平台 `model` 字段仅展示。

## 实现

- `src/shared/enterprise-agents.ts`：跨进程契约（PlatformAgentSummary / InstalledPlatformAgent / 判别联合结果类型）。
- `src/main/enterprise/auth.ts` 增 `apiGet(path)`：以当前会话调平台 GET，解析包络（业务错误 HTTP 200+code:4xx / 鉴权真 401 / 网络不可达），cookie 不出 auth。
- `src/main/enterprise/agents.ts`：`EnterpriseAgentStore`（listPlatformAgents / installAgent（下载=更新同路径，先挪旧目录再放新目录，Windows rename 兼容）/ listInstalledAgents / uninstallAgent（仅平台来源）/ syncAgents）+ `registerEnterpriseAgentHandlers`（六通道，isTrustedEvent 守卫）。
- 组合文件模板 = standard 预设通用子集（bash/pwsh/fs/fs-search/jobs/web/ask-user/todo/present + compaction 组），行内容逐字复制；`preset.yml` 标量用 JSON 字符串转义。
- `src/main/index.ts`：store 构造与注册、`showEnterpriseAgents`（镜像登录门禁导航）、restore/onEnter 后台同步（不阻塞门禁、失败静默）。
- `src/preload/`：`dshEnterprise` 桥扩展 6 方法；`enterprise-agents-button.ts` 侧边栏入口（enterprise-chip 接缝模式）。
- `build/agents.html`：卡片列表/状态机（loading/ready/empty/unreachable/unauthorized）、两步内联卸载确认、"已下载（平台上已不存在）"区。
- 顺带修复：`build/enterprise-login.html` 此前未列入 `package.json` extraResources（打包后缺文件）；`test/release.test.ts` 加"build/*.html ⊆ extraResources"泛化断言。

## 测试与验收

- vitest：auth apiGet 5 例；store 安装/消毒/YAML 结构/覆盖更新/拒绝路径/已装列表/卸载防护/同步三场景（新增共 36 例，依赖注入桩不 mock electron）。
- 手动（stub 平台 + 真实平台 3002）：列表→下载→选择器即时出现→运行 persona 生效（stub 与真实均验证；真实平台"DSH环境验证助手"按提示词先说明思路再 write_file 产出 note.txt）→ v3→v4 更新→两步卸载→unauthorized 态→登录后自动同步（未打开页面即落盘）→卸载后重启不装回。
- 遗留：Windows 目录 rename 序列实机验收。

## 明确不做（本期范围外）

- 平台知识库远程检索、平台 DB 工具、变体导出（二期待议）
- 平台侧接口实现（合同交付，平台仓库另行落地——已按合同上线）
- 取消分配后自动删除本地已装（保守保留，页面"已下载"区手动管理）
